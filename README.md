# Diodos — A Simple and Elegant Network Tool

Diodos is a modern network tool powered by the Clash core, featuring a beautiful interface and powerful functionality.

## Features

- 🚀 Integrated with the latest Clash core
- 📊 Clean and intuitive dashboard
- 🎬 Media service availability checks
- ⚡ Speed testing and result sharing
- 🔧 Convenient subscription management
- 🌐 System proxy toggle
- 💡 Light and dark theme support
- 🔔 System tray integration
- 🎨 Modern interface design

## Installation

### Download a Release

Visit the [Releases page](https://github.com/Devi766/Diodos/releases) to download the latest installer.

### Build from Source

```bash
# Clone the repository
git clone https://github.com/Devi766/Diodos.git
cd Diodos

# Install dependencies
npm install

# Run in Tauri development mode
npm run tauri:dev

# Build the installer
npm run tauri:build
```
